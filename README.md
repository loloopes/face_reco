### Face Recognition APP

Este é um Aplicativo de Reconhecimento Facial desenvolvido em Python para detecção e correspondência facial eficiente.
O aplicativo detecta rostos, extrai embeddings e identifica os rostos mais similares usando um algoritmo de similaridade cosseno. 
Os resultados, como caixas delimitadoras, são exibidos visualmente para melhor compreensão.

As bibliotecas utilizadas são:

* InsightFace: Detecta rostos e extrai embeddings com o módulo FaceAnalysis.
* OpenCV (cv2): Realiza leitura de imagens, pré-processamento e visualização dos resultados.
* NumPy: Executa operações numéricas, como cálculos de similaridade cosseno.
* Pandas: Organiza os embeddings faciais e metadados associados.
* O fluxo inclui detecção de rostos, cálculo de similaridade e apresentação das correspondências mais próximas, tornando-o ideal para verificação de identidade, controle de presença e soluções de segurança.

### Face Recognition APP

This is a Face Recognition App built in Python for efficient face detection and matching.
The app detects faces, extracts embeddings, and identifies the most similar faces using a cosine similarity algorithm.
Results, such as bounding boxes, are displayed visually for clarity.

The libraries used are:

* InsightFace: Detects faces and extracts embeddings using the FaceAnalysis module.
* OpenCV (cv2): Handles image reading, preprocessing, and result visualization.
* NumPy: Performs numerical operations like cosine similarity calculations.
* Pandas: Organizes face embeddings and associated metadata.
* The workflow involves detecting faces, calculating similarity, and presenting the closest matches, making it suitable for identity verification, attendance systems, and security solutions.
